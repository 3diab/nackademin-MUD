# Nackademin MUD

Startprojekt för MUD-övningarna i C#-kursen på Nackademin.

## Kom igång

1. Ladda ner projektet från GitHub.
2. Packa upp projektet på din dator.
3. Öppna projektet i Visual Studio.
4. Kontrollera att projektet går att köra.

## Skapa ett eget repository

Skapa ett **nytt repository på ditt eget GitHub-konto**.

Koppla sedan projektet till ditt nya repository:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <URL-TILL-DITT-REPO>
git push -u origin main
```

## Under kursen

Arbeta vidare i **ditt eget repository** och gör commits löpande:

```bash
git add .
git commit -m "Kort beskrivning av ändringen"
git push
```

Du ska alltså **inte pusha ändringar till detta startrepository**.
